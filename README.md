# RepoLens

RepoLens is a high-fidelity frontend prototype for GitHub repository intelligence. It helps developers orient quickly through architecture mapping, dependency risk signals, code composition, and commit velocity.

## Included

- Responsive developer-tool dashboard
- Simulated repository scan interaction
- Module dependency map
- Security and configuration-risk pulse
- Language composition and repository activity visualizations
- Priority inspection queue and natural-language prompt UI

## Run locally

Open `index.html` directly in a modern browser. No build step or dependencies are required.
